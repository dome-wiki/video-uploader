Privacy Policy

Effective date: October 16, 2026

This policy describes how youtube-upload (the "Tool") handles data. The Tool is a personal command-line program used only by its developer to upload the developer's own videos to the developer's own YouTube channels.

1. Who uses the Tool

The only user is the developer. The Tool is not distributed, sold or offered to anyone else, and it has no public sign-up.

2. Google user data the Tool accesses

When the developer signs in with Google OAuth, the Tool requests these scopes:

  • https://www.googleapis.com/auth/youtube.upload — to upload videos and set thumbnails on the developer's channel.
  • https://www.googleapis.com/auth/youtube.readonly — to read the signed-in channel's ID and title, so the Tool can confirm it is uploading to the intended channel.

The Tool does not request access to viewer data, comments, analytics, email, contacts or any other Google service.

3. How the data is used

  • The channel ID and title are compared with the developer's own configuration and printed on the developer's screen. They are not used for anything else.
  • Video files, titles, descriptions and thumbnails come from the developer's computer and are sent only to YouTube.

4. Storage and security

  • OAuth tokens are stored only on the developer's own computer, in a file readable only by the developer's user account (permission 600).
  • The Tool keeps a small local record of each upload (video ID, URL, upload time, privacy setting) next to the source video file.
  • No data is sent to any server other than Google's APIs. There is no database, analytics or tracking.

5. Sharing

The Tool does not sell, share or transfer Google user data to any third party. It does not use Google user data for advertising, and it does not use it to develop or train AI or machine-learning models.

6. Compliance

The Tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube is subject to the YouTube Terms of Service and the Google Privacy Policy.

7. Retention and deletion

The developer can delete the stored tokens at any time by removing the token file, and can revoke the Tool's access at Google Account permissions. Revoking access stops all further API use.

8. Changes

If this policy changes, the new version will be published on this page with a new effective date.

9. Contact

Questions can be filed as an issue on the GitHub repository.
