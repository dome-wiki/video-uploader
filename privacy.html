Privacy Policy

Effective date: October 18, 2026

This policy describes how Dome Video Uploader (the "Tool") handles data. The Tool is a personal command-line program used only by its developer to upload the developer's own videos to the developer's own YouTube channels.

1. Who uses the Tool

The only user is the developer. The Tool is not distributed, sold or offered to anyone else, and it has no public sign-up.

2. Google user data the Tool accesses

When the developer signs in with Google OAuth, the Tool requests these scopes:

  • https://www.googleapis.com/auth/youtube.force-ssl — to manage the developer's own videos on the developer's own channel: upload videos, set thumbnails, edit titles, descriptions, tags and publishing settings, add videos to playlists, upload caption files, and read the signed-in channel's ID and title so the Tool can confirm it is working on the intended channel.

The Tool only acts on videos that belong to the intended channel; it checks the channel of every video before changing it. It never deletes videos, rates videos or posts comments.

The Tool does not request access to viewer data, comments, analytics, email, contacts or any other Google service.

3. How the data is used

  • The channel ID and title, and the title, status and processing state of the developer's own videos, are compared with the developer's own configuration and printed on the developer's screen. They are not used for anything else.
  • Video files, titles, descriptions, tags, thumbnails and caption files come from the developer's computer and are sent only to YouTube.

4. Storage and security

  • OAuth tokens are stored only on the developer's own computer, in a file readable only by the developer's user account (permission 600).
  • The Tool keeps a small local record of each upload (video ID, URL, upload time, privacy setting) next to the source video file.
  • No data is sent to any server other than Google's APIs. There is no database, analytics or tracking.

5. Sharing

The Tool does not sell, share or transfer Google user data to any third party. It does not use Google user data for advertising, and it does not use it to develop or train AI or machine-learning models.

6. Compliance

The Tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

The Tool uses the YouTube API Services. By using the Tool, users agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

The Tool does not use cookies and does not place, access or recognize any information on the user's device or browser, other than the local token file described in section 4.

7. Retention and deletion

  • The Tool does not keep any data received from the YouTube API Services other than the ID and URL of the developer's own uploaded videos, which are kept only in the local upload record.
  • The developer can delete the stored tokens and upload records at any time by removing the files on their computer.
  • Access can be revoked at any time at the Google security settings page. Revoking access stops all further API use. When access is revoked, the local token file is deleted within 7 days.

8. Changes

If this policy changes, the new version will be published on this page with a new effective date.

9. Contact

Questions can be filed as an issue on the GitHub repository.
